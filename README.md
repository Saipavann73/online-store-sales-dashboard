# 🛍️ Online Store Sales Dashboard

## 📌 Project Overview

The **Online Store Sales Dashboard** is a data visualization mini project developed to analyze and monitor the performance of an online store. It provides an interactive view of sales data using charts, graphs, and key performance indicators (KPIs).

The dashboard helps identify sales trends, top-selling products, customer purchasing patterns, and overall store performance.

## 🎯 Objectives

* Analyze online store sales performance.
* Track revenue and order trends.
* Identify top-selling products.
* Analyze category-wise sales performance.
* Compare sales across different regions or segments.
* Visualize important business metrics.
* Generate useful insights from sales data.

## ✨ Key Features

* 📈 Sales trend analysis
* 💰 Revenue tracking
* 🛒 Order and quantity analysis
* 🏆 Top-selling product analysis
* 📦 Category-wise sales analysis
* 🌍 Region-wise sales analysis
* 📊 Interactive charts and graphs
* 🔎 Data filtering and exploration
* 📌 KPI cards for quick insights

* **Pandas** – Data cleaning and manipulation
